# Ycap_Streamlit 🚀

A collection of hands-on **Streamlit applications, Python data analysis experiments, and AI/LLM projects** developed during the YCAP Streamlit session.

This repository covers Streamlit fundamentals, data analysis, IoT sensor data visualization, document processing, LangChain, embeddings, FAISS, Ollama, and local Large Language Models.

---

## 🚀 Overview

The repository contains multiple experiments and applications developed while learning and working with Streamlit and AI technologies.

The main areas explored are:

- Streamlit application development
- Interactive UI components
- Python data analysis
- Pandas and NumPy
- IoT sensor data analysis
- Data visualization
- CSV data processing
- PDF and text document processing
- LangChain
- Hugging Face embeddings
- FAISS vector database
- Ollama
- Gemma 2B
- Retrieval-Augmented Generation (RAG)
- AI-powered document chat
- Resume analysis using LLMs
