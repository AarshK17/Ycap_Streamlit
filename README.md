# Ycap_Streamlit

Ycap Streamlit Session — a collection of hands-on Streamlit applications and experiments covering Streamlit UI components, data handling, and integration with Large Language Models using LangChain and Ollama.

## 🚀 Overview

This repository contains the projects and experiments developed during the YCAP Streamlit session.

The repository explores:

- Streamlit application development
- Interactive UI components
- Data handling with Pandas
- File uploading and processing
- Data visualization
- LangChain integration
- Ollama and local LLMs
- AI chatbot development

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- LangChain
- Ollama
- Gemma 2B
- FAISS
- Sentence Transformers
